# Claims and evidence register

No security or resilience claim should be strengthened in release copy without adding
evidence here. “Pending” claims are design goals, not release guarantees.

| Claim                                                                              | Evidence                                                                                                                                                                                                                                                                                                          | Status / limitation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Core processing is local and makes no network requests                             | Manifest tests, package scan, CSP `connect-src 'none'`                                                                                                                                                                                                                                                            | Verified for public builds; hosted code delivery remains a trust surface. `stegoshard ui` (npm CLI) and the offline bundle's `serve.mjs` **listen** on 127.0.0.1 when asked; still no outbound request, and the released binaries hold no network permission at all                                                                                                                                                                                                                                                                       |
| Confidentiality uses Argon2id and AES-256-GCM                                      | `SPEC.md` §§5–6, crypto vectors, TS/Python conformance; AES-256-GCM, SHA-256 and HMAC-SHA256 additionally checked against NIST CAVP and Wycheproof vectors via crypto-condor (`tests/compliance`)                                                                                                                 | Independent audit pending. The third-party vectors cover AES-GCM and the hashes only: **Argon2id and HKDF have no such coverage**, since crypto-condor has no module for either. Their evidence remains the two implementations agreeing on frozen vectors                                                                                                                                                                                                                                                                                |
| Sampled `randomBytes` output passes the NIST battery within a calibrated tolerance | NIST battery (TestU01) over 8 MiB with the user-entropy layer off, rich, and degenerate (`tests/compliance/test_randomness.py`)                                                                                                                                                                                   | A smoke test for detectable distribution defects, nothing more. It does **not** establish unpredictability, which no statistical battery can: a counter encrypted under a fixed key passes them all. It does not simulate a failed CSPRNG. And it is **not evidence about steganographic detectability**: steganalysis compares a carrier against a natural-image model, where a uniformly random bit-plane is itself a tell                                                                                                              |
| Malformed input is resource-bounded                                                | Parser tests, fuzzing, browser preflight and post-decode caps                                                                                                                                                                                                                                                     | Browser limits differ from the 1 GiB CLI binary limit                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Missing image shards can be recovered                                              | Reed–Solomon property and pipeline tests                                                                                                                                                                                                                                                                          | Only within the encoded `m` parity budget                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Generated disk images round-trip losslessly                                        | Post-save verification and codec tests                                                                                                                                                                                                                                                                            | Does not prove survival through arbitrary third-party processing                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Printed recovery survives supported capture conditions                             | `docs/QA.md` physical matrix                                                                                                                                                                                                                                                                                      | **Pending physical sign-off; do not advertise as a universal guarantee**                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Deniable paths avoid explicit mode/region errors                                   | Access-structure tests and fixed candidate schedule                                                                                                                                                                                                                                                               | Not a formal timing, forensic-indistinguishability, legal, or coercion guarantee                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Deniable carriers survive off-the-shelf triage                                     | zsteg differential test over four CC0 photographs: the carrier presents the same structural findings and text-fragment counts as the untouched cover (`tests/steganalysis`)                                                                                                                                       | PNG carriers only; the JPEG carrier has a separate and narrower measurement, in the row below. StegExpose additionally shows the carrier scoring identically to a clean cover (0.031-0.096), but at 0.035% embedding that is below the detectors' sensitivity, not evidence of resistance to steganalysis                                                                                                                                                                                                                                 |
| The JPEG carrier does not move a JPEG steganalyser                                 | Aletheia over five camera originals: on the two covers where an outguess control is demonstrably detected in CI, the carrier scores within the 0.1 reporting granularity of its untouched cover (identical on four of five covers; `beach` moves 0.1 to 0.2) (`tests/steganalysis`, nightly)                      | Rests on **one** working detector over **two** covers: three of Aletheia's four saturate on this set, flagging clean photographs. The detectors are learned, so a low score may mean undetectable **or** outside the training distribution. Not a general claim of resistance to JPEG steganalysis                                                                                                                                                                                                                                        |
| New credentials meet a 12-character minimum                                        | `meetsPasswordFloor` + policy tests; enforced on every save/key-creation surface and not waivable by `--allow-weak-password`                                                                                                                                                                                      | A length floor, not a strength guarantee: `aaaaaaaaaaaa` clears it. The advisory tier (16+ chars, 80+ estimated bits) warns but is dismissible by design. Existing vaults created under the old policy still open; restore deliberately does not apply the floor                                                                                                                                                                                                                                                                          |
| The erasure code is the construction the specification describes                   | The Cauchy matrix, the Gauss-Jordan inverter, the MDS property and the frozen parity bytes checked against `galois`, a finite-field linear-algebra engine, over all 192 layouts the encoder produces, k=1 to the Gallery maximum of 190 plus the two colour-grid layouts, on every pull request (`tests/erasure`) | Establishes that the specification, both implementations and an independent engine agree. Does **not** establish that the formula is a sound design choice: transcribing SPEC §7.4 into the reference is a human act, and a specification wrong in the same way as the code would pass. MDS is exhaustive on 13 of the 192 layouts and sampled on the rest (26,359 submatrices in total), since `C(154,135)` has 33 digits. For a Cauchy matrix MDS is a theorem, so the sweep guards the implementation rather than proving the property |
| The Galois field under erasure coding is the one the specification names           | Both stacks compared exhaustively on every pull request (`tests/erasure`): the 65,536 products against reedsolo **and** against a table-free carry-less multiply; the 65,280 quotients, 255 inverses and exp/log tables against reedsolo alone                                                                    | Anchors the **field only**; this row on its own says nothing about the code built on it, which is covered by the row above. reedsolo is an independent implementation, not a standards authority: there are no standardised vectors for this 0x11D field, unlike the 0x11B field of AES                                                                                                                                                                                                                                                   |
| Independent recovery remains possible                                              | Python decoder and fresh-fixture CI conformance                                                                                                                                                                                                                                                                   | Current format is a pre-1.0 candidate until audit closure                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| No analytics, telemetry, or host permissions ship                                  | Source scan, manifest/package checks, privacy policy                                                                                                                                                                                                                                                              | Downloaded release provenance must still be verified                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
