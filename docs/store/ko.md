**작고 소중한 파일을 비밀번호로 잠그고, 오래 살아남을 곳이나 아무도 찾지 못할 곳에 보관하세요.**

StegoShard 는 민감한 파일(비밀번호 관리자 내보내기, 암호화폐 지갑 복구 문구, 계정 백업 코드, 개인 키, 비밀 메모)을 몇 년이고 안전하게 보관할 수 있는 형태로 바꿔 줍니다. 암호화한 다음 선택하세요. 인쇄하고 복사하고 다시 내려받아도 견디는 튼튼한 오류 정정 이미지(또는 인쇄용 페이지, 또는 단일 파일)로 저장하거나, 평범해 보이는 사진 속에 눈에 띄지 않게 숨겨 존재 자체를 감출 수 있습니다. 물론 두 가지를 동시에 할 수도 있습니다.

모든 작업은 사용자의 기기에서 이루어집니다. 업로드되는 것도, 계정도 없으며, 오프라인에서 동작합니다.

**이런 데 쓸 수 있습니다**

- 비밀번호 관리자 내보내기를 클라우드 회사에 맡기지 않고 몇 년이고 보관하고, 인쇄해 두면 노트북이 망가져도 함께 사라지지 않습니다.
- 암호화폐 지갑 복구 문구를 지키세요. 아주 작고, 대체할 수 없으며, “비밀번호 찾기”도 없습니다.
- 암호화된 백업을 QR 코드 PDF 로 인쇄해 두었다가, 나중에 휴대폰 카메라로 페이지를 찍어 복원하세요. 한 장을 잃거나 얼룩져도 괜찮습니다.
- 비밀번호나 키 백업을 앨범에 남겨 둔 가족사진 속에 숨겨, 그 존재 자체를 드러내지 않게 하세요.
- 비밀을 여러 장의 평범한 사진과 미끼 사진에 나눠 보관하세요. 몇 장을 잃어도 괜찮습니다.
- 계정 복구 코드를 보관하고, 일부 사본이 손상되어도 원본 파일을 바이트 단위 그대로 되찾으세요.

**기능**

- 비밀번호 기반 암호화. 키는 기기를 벗어나지 않습니다(Argon2id + AES-256-GCM)
- 평범한 사진 속에 비밀 숨기기: JPEG 는 JPEG 로, PNG 는 PNG 로 남습니다
- 여러 이미지에 걸친 오류 정정: 페이지나 사진을 잃어도 복원됩니다
- 인쇄용 종이 / QR 내보내기. 스캐너나 휴대폰 카메라로 복원할 수 있습니다
- 이미지나 단일 .zip 으로, 또는 내용이 드러나지 않는 파일 하나로 디스크에 저장
- 위장 데이터베이스(.db) 출력과 갤러리 모드(일상 사진에 나눠 숨기기)
- 키를 다루는 세 가지 방법: 내장, 별도의 키 파일, 또는 사진 속에 숨기기
- 비밀번호 강도 표시와 암호구 생성기, 첫 실행 안내 포함
- Chrome, Edge, Firefox 에서 동작하며, 설치가 필요 없는 웹 앱도 함께 제공합니다

**설계부터 사생활 중심**
무료 오픈 소스(MIT)입니다. 계정도 추적도 없으며, 선택한 파일은 기기에서 처리됩니다. 웹 앱과 독립 디코더가 별도의 복구 경로를 제공합니다. 형식에는 버전이 매겨져 있지만 아직 1.0 이전의 베타 후보입니다.

**유의하세요**
StegoShard 는 작은 비밀을 위한 것이지 드라이브 전체 백업용이 아닙니다. 비밀번호를 잃으면 복구할 방법이 없으니 안전하게 보관하세요. 비밀을 숨기는 것은 무심코 훑어보는 눈은 막아 주지만, 작정한 포렌식 조사관을 막아 준다는 보장은 아닙니다. 베타 소프트웨어입니다.
