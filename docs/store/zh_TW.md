**用密碼保護小巧而珍貴的檔案 — 並將其存放在能長久留存，或是誰也找不到的地方。**

StegoShard 能將敏感檔案 — 密碼管理器的匯出檔、加密錢包的復原助記詞、帳號備用碼、私鑰、機密筆記 — 轉換成能安全保存多年的形式。加密後，您可以選擇：將其儲存為強健且具備錯誤更正功能的圖片（或可列印的頁面、單一檔案），使其在經歷列印、複製與重新下載後依然完好無損 — 或者是將其無形地隱藏在看似平凡的照片中，讓人根本無從察覺其存在。您也可以同時使用這兩種方式。

一切都在您自己的裝置上完成。沒有任何資料會被上傳，不需要建立帳號，且完全支援離線運作。

**您可以用它來做什麼**

- 備份密碼管理器的匯出檔並保存多年，無須信任任何雲端公司 — 您還可以將其列印出來，即使筆記型電腦損壞，資料也不會跟著消失。
- 保護加密錢包的復原助記詞 — 體積極小、無可取代，且沒有「忘記密碼」的補救機制。
- 將加密備份列印為 QR code PDF，日後只需用手機相機掃描頁面即可復原 — 就算遺失一頁或沾染污漬也能成功還原。
- 將密碼或金鑰備份隱藏在相簿裡的家庭照片中，讓它的存在本身保持低調。
- 將祕密分散隱藏在多張平凡照片與誘餌檔案中 — 遺失幾張也無妨。
- 儲存帳號復原碼，即使部分副本毀損，也能完美還原原始檔案的每一個位元組。

**主要功能**

- 密碼加密；您的金鑰絕不會離開裝置（Argon2id + AES-256-GCM）
- 將祕密隱藏在平凡照片中 — JPEG 依然是 JPEG，PNG 依然是 PNG
- 跨多張圖片的錯誤更正功能：就算遺失一頁紙或一張照片，仍可順利復原
- 可匯出為紙本列印 / QR 碼，透過掃描或手機相機即可復原
- 可將其儲存至磁碟為圖片、單一 .zip 檔，或是內容無法辨識的單一檔案
- 產生誘餌資料庫（.db）與相簿模式（分散於日常照片中）
- 三種金鑰處理方式：內嵌、獨立金鑰檔，或隱藏於照片中
- 內建密碼強度量表與通關密語產生器，並於首次啟動時提供引導教學
- 支援 Chrome、Edge 與 Firefox，另有免安裝的同等功能網頁版應用程式

**注重隱私的設計**
免費且開放原始碼（MIT）。免帳號、無追蹤；您選取的檔案會在裝置上處理。網頁版與獨立解碼器提供兩條分開的復原途徑。格式具版本控制，但在 1.0 前仍是 Beta 候選版本。

**請注意**
StegoShard 是專為小型祕密設計的，並非用於全機備份。若您遺失密碼，將無法復原 — 請妥善保管您的密碼。隱藏祕密能讓它避開不經意的目光，保持低調；但這並非能絕對抵禦專業數位鑑識分析的保證。本軟體目前為 Beta 版。
